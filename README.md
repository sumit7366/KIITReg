# 🎓 KIITReg

> Internal event registration platform for **SCA KDev, KIIT**, enabling students to register for technical events, participate in competitions, view quiz scores, and download certificates.

---

## 📖 Overview

KIITReg is an internal web application developed for the **SCA KDev** community at **KIIT University**. It streamlines event management by providing a centralized platform where students can discover and register for various technical events while organizers can efficiently manage registrations and participant information.

Students can:

- 📝 Register for workshops, quizzes, hackathons, and other technical events
- 📊 View quiz scores and results
- 📄 Access and download participation or achievement certificates
- 👤 Manage their profile and event registrations

---

## ✨ Features

- 🔐 Secure authentication using Firebase Authentication
- 📅 Event registration and management
- 🏆 Quiz score tracking
- 📜 Certificate access and downloads
- 👤 Student dashboard
- ⚡ Fast and responsive UI
- 📱 Fully responsive design

---

## 🛠️ Tech Stack

### Frontend

- Next.js
- React
- TypeScript

### Backend & Services

- Firebase Authentication
- Firebase Firestore
- Firebase Storage

## 🚀 Getting Started

```bash
git clone https://github.com/sumit7366/KIITReg.git

cd KIITReg

git checkout dev

npm install

npm run dev
```

Open **http://localhost:3000** in your browser.
